# Game of Trains (C)

A C implementation of the "Game of Trains" card game, developed to practice low-level programming concepts including pointer-based data structures, memory management, and control flow.

## About Game of Trains
Game of Trains is a card game where players compete to arrange their train cars (numbered cards) in ascending order by drawing, replacing, or using special power cards. The game combines strategic decision-making with pattern recognition in short, engaging rounds.

## Features
- Core game mechanics implemented using structs, arrays, and pointers
- Dynamic game state management across multiple players
- Modular design with functions handling card operations, player actions, and game rules
- Emphasis on manual memory handling and structured control flow

## Technologies & Concepts
- Language: C
- Key concepts: pointers, structs, arrays, memory management, function decomposition
- Tools: OnlineGDB, GCC compiler

## Learning Outcomes
- Gained hands-on experience debugging pointer-related issues and undefined behavior
- Strengthened understanding of C memory model and data manipulation
- Practiced translating complex game rules into structured program logic
